# [Bài tập] Thiết kế Trang Giới Thiệu Sản Phẩm

Bài tập thiết kế trang giới thiệu sản phẩm cao cấp lấy cảm hứng từ trang sản phẩm Apple iPhone, ứng dụng Bootstrap Grid System, Flexbox, Display, Margin & Padding và Font Awesome theo chuẩn CodeGym.

## Các đặc điểm nổi bật
- **Header & Hero Section**: Tiêu đề sản phẩm iPhone 16 Pro với hiệu ứng gradient titan, nút bấm bo góc tròn (`rounded-pill`) căn chỉnh bằng Flexbox và ảnh mockup sản phẩm.
- **Lưới tính năng (Grid & Flexbox)**: 4 thẻ card nổi bật (Chip A18 Pro, Camera 48MP Fusion, Khung Titanium, Pin bền bỉ) tương thích linh hoạt trên mọi độ phân giải.
- **Font Awesome Icons**: Trực quan hóa thông số kỹ thuật với bộ icon hiện đại (`fa-microchip`, `fa-camera`, `fa-shield-alt`, `fa-battery-full`).
- **Call to Action**: Khối kêu gọi đặt mua tương tác với bố cục chia cột responsive.
- **Footer chuẩn Apple**: Hệ thống liên kết phân cấp và bản quyền.

## Công nghệ sử dụng
- HTML5
- Bootstrap 5.3.3
- Font Awesome 6.5.2
